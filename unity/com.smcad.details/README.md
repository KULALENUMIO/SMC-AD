# SMC-DETAILS for Unity（仮）

> **試作です。** SMC-AD で取り込んだ機体に、Unity の中で汚しを付けます。Blender 版 SMC-DETAILS の代わりです。

塗装の質感（色の変調・退色・色ムラ・フィルター・ポストシェーディング・スミ入れ・エッジハイライト・雨だれ）と、
傷・錆・塗装ハゲ・くすみ・泥・土・砂・濡れを、スライダーとプリセットで付け、ブラシで足したり消したりします。
UV 展開も焼き込みも使いません。スライダーは即座に反映されます。

- 必要なもの: `com.smcad.unity` 0.4 以降（SM Lit シェーダ）、**HDRP 17.3 以降**（0.2.0 から HDRP 専用。URP 版は `urp-final` タグ）。デカールを使うときは HDRP アセットの Decals を有効に
- 開き方: メニュー **Tools > SMC-AD > 汚し（SMC-DETAILS）**、機体を選ぶ →「汚しを付ける（形を解析）」

## 仕組み

1. **形の解析（GPU、1 秒以内）**: 機体のまわりを 3 cm 前後の格子に分け、96 方向から深度を描いて、
   各点が何方向から見えるかを数えます（平らな面の前 ≈ 半分、角 = 多い、くぼみ = 少ない）。結果は 3D テクスチャ 1 枚。
2. **頂点に「解析した時の位置と向き」を持たせる**（追加の頂点ストリーム UV5 / UV6。部品の角までの距離は UV1 / UV7）。関節で部品が動いても汚れはずれません。
3. **SM Lit の汚し層（`_SMCAD_DETAILS`）が全部その場で計算**: 角・くぼみ・地面からの高さ・上向き・ノイズから
   汚れの量を出し、細かい 3D ノイズで境目をくっきりさせ、色・ざらつき・凹凸を重ねます。
4. **手描き**: 3D の格子（形の格子の半分の細かさ）にブラシで描きます。UV の継ぎ目はありません。
5. **一緒に付いてくる部品**（機体の隣の `Track_*`、Tank Rigging プラグインの履帯）も汚します
   - 車輪・転輪・フレーム（HDRP/Lit）は「SMC-AD/Details Lit」（HDRP/Lit 相当＋汚し、プロパティ名も同じ）の複製に差し替え、機体と同じ汚れが付きます
   - 履帯のリンクは土汚れだけ（量は「履帯（リンク）」のスライダー）。リンクのプレハブを汚し用の複製（`*_SMD.prefab`）に差し替えます
6. 元のマテリアルは変えず、汚し用の複製（`Assets/SMCAD_Details/<機体>/`）に差し替えます。「汚しを外す」で元に戻ります。

## 制限（試作）

- 部品を大きく動かした・足したときは「形を解析し直す」（格子の大きさが変わると手描きは消えます）
- 見えない面が削られた薄い殻の部品では、角の判定が広めに出ることがあります（「角の検出の強さ」で調整）
- デカールは HDRP の Decal Projector（`HDRP/Decal`、色だけを載せる）です。デカールの上には汚しが乗りません
- ゲーム中の描画コストは未計測です（汚しを画像に固める機能はまだありません）
