# SMC-AD+ Surfaces（仮称）

> **α版・実験的な試作品です。** 気まぐれで更新しているので、まともな更新やサポートは期待しないでください。正式版にするときは、リポジトリを削除するか置き換えるかもしれません。

SMC-AD の拡張です。マテリアルに「材質タイプ」（塗装金属・地金・ゴム・プラスチック・木・石）を付けます。
シェーダエディタを開かずに、サイドバーだけで操作できます。

- 必要なもの: SMC-AD 0.3.0 以上（先に有効にしてください）
- 有効にする順番: SMC-AD → SMC-AD+ Surfaces
- 外しても、付けた材質のノードは .blend に残るので、見た目は変わりません

ノード構成とのつながり方は `surfaces.py` の先頭のコメントにあります。
